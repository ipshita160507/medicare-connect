# MediCare Connect – Hospital Management System

A full-stack web application built with **React, TypeScript, Tailwind CSS, and Supabase (PostgreSQL)** to digitize hospital operations.

## Key Features
- Authorized Staff Authentication: Secure login system powered by Supabase Auth.
- Doctor Directory: Searchable directory of hospital specialists with availability schedules.
- Appointment & Prescription Management:Online appointment booking, status tracking, and digital prescription generation.
- Real-Time Emergency Bed Tracker:Live ward capacity monitoring (ICU, General Ward, Emergency) with automated critical-low alerts.
